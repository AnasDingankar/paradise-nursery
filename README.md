# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application built using React and Redux.

The application allows users to browse a variety of houseplants, view plant names, images, descriptions, and prices, and add plants to a shopping cart.

## Features

- Paradise Nursery landing page
- Houseplants grouped into different categories
- Add plants to the shopping cart
- Dynamic shopping cart item count
- Increase or decrease plant quantities
- Remove plants from the cart
- Calculate individual and total cart costs
- Continue shopping option
- Checkout functionality

## Technologies Used

- React
- Redux
- JavaScript
- HTML
- CSS
